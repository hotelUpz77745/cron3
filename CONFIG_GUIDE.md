# Гайд по архитектуре и конфигурации бота

Вся конфигурация бота строится на двух ключевых файлах с чётким разделением ответственности:
1. `CFG/app.json` — инфраструктура приложения (системные параметры, диспетчер `active_strategies`, Telegram, риски).
2. `CFG/universes.json` — единая база торговых шаблонов (Вселенных), полностью определяющая параметры торговли, купола стратегии и изолированные настройки сторон (`LONG` и `SHORT`).

---

## 1. Инфраструктура и Диспетчер (`CFG/app.json`)

Файл `app.json` отвечает за среду исполнения и распределение монет по стратегиям:

### Раздел `active_strategies` (Диспетчер Вселенных)
Связывает монеты с шаблонами Вселенных из `universes.json`. Строго соблюдается взаимная однозначность 1:1 (одна монета торгуется строго одной стратегией):
```json
"active_strategies": {
    "u9_omni_zenith_apex": {
        "enabled": true,
        "symbols": ["GRASSUSDT", "ARXUSDT", "ZROUSDT"]
    },
    "u0_base_classic_supergrid": {
        "enabled": false,
        "symbols": []
    }
}
```

### Раздел `app` (Системные настройки)
- **`auto_start`** *(true/false)* — если `true`, бот сразу начинает торговать при запуске.
- **`time_zone`** — часовой пояс для логов и отчетов (например, `"UTC"`).
- **`req_timeout_sec`** — максимальное время ожидания ответа от Binance (обычно 10 секунд).

### Раздел `telegram`
- **`enabled`** *(true/false)* — включить или выключить управление через Telegram.
- **`allowed_users`** — список ID пользователей Telegram (числа без кавычек), которым разрешено управлять ботом.

### Раздел `stop_bot_rirk_system` (Аварийный стоп)
- **`enabled`** *(true/false)* — включить систему защиты депозита.
- **`roi_critical_level_pct`** — уровень просадки в процентах (например, `-41`), при котором бот остановит торговлю.

### Раздел `volatility_scanner` (Скринер волатильности / Сонник)
Многофакторный каскадный скринер фьючерсного рынка Binance (запуск через Telegram: `/sonnik` -> кнопка «Run Scanner»).
Фильтрует монеты последовательно через цепочку независимых фильтров:
- **`min_dayly_vol_usdt`**: базовый фильтр ликвидности по суточному объему (например, от $3,000,000).
- **`strict_window`**: отбрасывать монеты с неполной историей свечей.
- **`atr_volatility_filter`**:
  - `timeframe`: таймфрейм для оценки свечной волатильности (по умолчанию `1w`).
  - `window`: окно усреднения свечей (например, 12).
  - `min_volatility_pct` / `max_volatility_pct`: допустимый диапазон волатильности (25.0% .. 40.0%).
- **`rsi_filter`**:
  - `timeframe`: таймфрейм свечей (например, `4h`).
  - `period`: период RSI (14).
  - `min_rsi` / `max_rsi`: коридор нормального RSI (35.0 .. 65.0) для отсева сильных пампов и дампов.
- **`bollinger_width_filter`**:
  - `timeframe`: таймфрейм полос Боллинджера (`4h`).
  - `MA_type`: тип средней линии (`"SMA"` или `"EMA"`).
  - `period` / `multiplier`: период (20) и множитель сигм (2.0).
  - `min_width_pct` / `max_width_pct`: допустимая ширина канала Боллинджера относительно нижней границы:
    $$\text{BB Width} = \left(\frac{\text{Upper Band}}{\text{Lower Band}} - 1\right) \times 100\%$$
    (по умолчанию 8.0% .. 13.0%).
  - **`center_proximity_filter`**:
    - `max_deviation_from_center_pct`: максимальное отклонение цены от `middleBB` в процентах от общей ширины канала:
      $$\text{Dev Pct} = \left(\frac{|Price - middleBB|}{\text{Upper Band} - \text{Lower Band}}\right) \times 100\% \le 75\%$$
      Гарантирует старт бота из сбалансированной средней зоны.

## 2. Торговые Вселенные (`CFG/universes.json`)

`universes.json` является **единственным источником истины** торговых параметров. Каждая Вселенная самодостаточна и не требует внешних обёрток:

### Уровень Вселенной (Стратегические купола)
- **`name`** / **`description`** — человекочитаемое имя и описание Вселенной.
- **`start_balance_usdt`** — базовый баланс Вселенной для аналитики.
- **`leverage`** — плечо по умолчанию (например, 20).
- **`timeframe`** — рабочий таймфрейм свечей (например, `"5m"`).
- **`super_grid`** — защита от аномальной волатильности (динамическое масштабирование шагов сетки).
- **`analytics`** — персональный купол учета PnL и ROI.
- **`notifications`** — персональные пороги уведомлений в Telegram.
- **`auto_closing`** — купол фиксации профита / авто-закрытия (velocity/stagnation):
  - `negative` — аварийный стоп купола (`threshold` в USDT).
  - `positive` — фиксация прибыли по скорости или возрасту пика:
    - `min_floor` — минимальный пол профита (USDT), ниже которого цель не опустится при стагнации.
    - `mode` — `'velocity'` ($/ч) или `'time'` (часы с пика).
    - `velocity_pct_of` — база расчета процентов: `'top_target'` (от верхнего таргета) или `'target'` (от таргета уровня). Обеспечивает инвариантность к масштабированию объемов.
    - `stagnation_card` — карта ступеней затухания. Поддерживает как относительные проценты (`">5.0%"`, `">2.0%"`, `"<=2.0%"`), так и абсолютные числа (`">1.0"`).
- **`smart_grace`** — динамические задержки перед усреднениями.
- **`smart_size`** — купол Knife Blocker и деэскалации объемов.
- **`smart_tp`** — купол адаптивного тейк-профита по импульсу.

### Уровень Стороны (`LONG` и `SHORT`)
Все параметры торгового исполнения строго изолированы внутри купола конкретной стороны:
```json
"LONG": {
    "invest_size": 600.0,
    "grid": {
        "0": { "indent": 0.0, "volume": 7.0, "super_indent": null },
        "1": { "indent": -3.0, "volume": 7.7, "super_indent": null }
    },
    "tp_map": {
        "0": { "indent": 1.8, "fallback_indent": 2.6 },
        "1": { "indent": 1.35, "fallback_indent": 2.0 }
    }
},
"SHORT": {
    "invest_size": 600.0,
    "grid": { ... },
    "tp_map": { ... }
}
```

- **`invest_size`** — объем маржи (в USDT) на сетку данной стороны.
- **`grid`** — сетка усреднений (`indent` — отступ в %, `volume` — процент от общего объема; сумма объемов всех уровней строго равна 100.00%).
- **`tp_map`** — карта тейк-профитов для каждого шага усреднения (`indent` строго >= 0.50% по Правилу 11).

## Порядок запуска бота:
1. В `.env` пропишите `API_KEY`, `API_SECRET` и `TG_TOKEN`.
2. В `CFG/app.json` впишите свой ID телеграма в `allowed_users`.
3. В `CFG/app.json` в блоке `active_strategies` включите желаемую Вселенную (`"enabled": true`) и задайте список монет (`symbols`).
4. Запустите `main.py`. Перейдите в Telegram и нажмите кнопку **Start**.
