# Гайд по настройке бота для новых пользователей

Вся конфигурация бота разделена на два основных файла:
1. `app.json` — глобальные настройки приложения (какие монеты торговать, настройки Telegram, защиты и автоматика).
2. `_base.json` — торговая стратегия (сетки ордеров, тейк-профиты, плечи), которая применяется к каждой монете.

---

## 1. Глобальные настройки (`app.json`)

Этот файл находится в папке `CFG/app.json`.

### Раздел `app` (Системные настройки)
- **`auto_start`** *(true/false)* — если `true`, бот сразу начинает торговать при запуске. Если `false`, он запустится в режиме паузы (нужно будет нажать "Start" в Telegram).
- **`time_zone`** — часовой пояс для логов и отчетов (например, `"UTC"`).
- **`req_timeout_sec`** — максимальное время ожидания ответа от Binance (обычно 10 секунд).
- Остальные системные параметры (`precision`, `time_slack_sec`, задержки) лучше **не трогать**, они настроены оптимально под API Binance.

### Раздел `signal` (Логика входа)
- **`timeframe`** — таймфрейм для анализа волатильности (например, `"5m"`).
- **`smart_grace`** — умная система задержек между ордерами (чтобы не набирать позицию слишком быстро на резких проливах).
  - `start_period_sec`: стартовая задержка (в сек).
  - `eval_window_sec`: окно оценки тренда.

### Раздел `telegram`
- **`enabled`** *(true/false)* — включить или выключить управление через Telegram.
- **`allowed_users`** — список ID пользователей Telegram (числа без кавычек), которым разрешено управлять ботом. **Обязательно впишите сюда свой ID**.

### Раздел `symbols`
- Список торговых пар, которыми будет торговать бот (например, `["XRPUSDT", "BTCUSDT"]`). 

### Раздел `auto_closing` (Авто-закрытие позиций по PnL)
- **`positive`** / **`negative`**
  - `threshold`: При достижении какого профита (в USDT) бот автоматически закроет все сделки по всем монетам.
  - `threshold_increment`: Шаг увеличения порога (если закрыли в плюс 20$, следующий порог станет 40$).
  *(Если не используете, поставьте `null`)*.

### Раздел `stop_bot_rirk_system` (Аварийный стоп)
- **`enabled`** *(true/false)* — включить систему защиты депозита.
- **`roi_critical_level_pct`** — уровень просадки в процентах (например, `-41`), при котором бот остановит торговлю, чтобы не допустить ликвидации.

### Раздел `super_grid` (Защита от сильной волатильности)
Эта система переводит сетку на расширенные отступы (`super_indent`), если рынок сильно штормит. Настраивается глобально:
- **`enabled`** *(true/false)* — включить или выключить режим Super Grid.
- **`timeframe`** и **`window`** — на каком графике и за сколько свечей замерять волатильность (например, `1w` и `12`).
- **`min_volatility_pct`** — минимальная волатильность в процентах (например, `15.0`), при которой активируется Super Grid.
- **`multiplier`** — множитель для динамического расчета отступов (если не заданы жесткие `super_indent`).

## 2. Настройки сетки ордеров (`_base.json`)

Этот файл находится в папке `CFG/_base.json` и определяет торговую математику. По умолчанию настройки дублируются для **LONG** и **SHORT** направлений.

- **`enable`** *(true/false)* — включить или выключить торговлю в этом направлении.
- **`invest_size`** — объем маржи (в USDT), который бот будет использовать на всю сетку ордеров для одной монеты.
- **`leverage`** — кредитное плечо (например, `10`).
- **`margin_type`** — тип маржи: `"CROSSED"` (кросс-маржа) или `"ISOLATED"` (изолированная маржа).
- **`tp_purpose`** — логика перестановки тейк-профита (`"both"` — стандартная, двигается вслед за усреднением).

### Сетка усреднений (`grid`)
Это уровни, на которых бот будет докупать монету, если цена пойдет против него.
Каждый уровень (от `"0"` до `"5"` и т.д.) имеет:
- **`indent`**: На сколько процентов цена должна уйти в минус от точки входа, чтобы сработал этот уровень (например, `-5.0` означает просадку в 5%). *Уровень "0" — это первый вход в рынок (всегда `indent: 0`).*
- **`volume`**: Размер ордера в USDT. Сумма всех `volume` в сетке не должна превышать `invest_size * leverage`.
- **`super_indent`**: Этот параметр вам **не нужно настраивать вручную**. Он рассчитывается ботом автоматически, если в `app.json` включена система `super_grid`. Бот сам расширит отступы на основе заданного там `multiplier`, когда на рынке начнется сильная волатильность.

### Сетка Тейк-Профитов (`tp_map`)
Определяет, на каком расстоянии от *средней цены входа* будет стоять ваш тейк-профит.
Номер уровня в `tp_map` соответствует текущему шагу усреднения.
- **`indent`**: Стандартный профит в процентах (например, `0.6` = 0.6% чистого движения цены).
- **`fallback_indent`**: Запасной тейк-профит, который применяется при определенных рыночных условиях (когда боту нужно быстрее выйти из позиции).

## 💡 Порядок запуска для новичка:
1. В `CFG/app.json` впишите нужные монеты в блок `symbols`.
2. В файле `.env` пропишите `API_KEY`, `API_SECRET` и `TG_TOKEN`.
3. В `CFG/app.json` впишите свой ID телеграма в `allowed_users`.
4. Настройте `invest_size` и сетку `grid` в `CFG/_base.json` согласно вашему риск-менеджменту.
5. Запустите `main.py`. Перейдите в Telegram и нажмите кнопку **▶️ Start**.
