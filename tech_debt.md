  2. **Универсальный архитектурный инвариант трейлинга: Геометрия «ПОЛ / КУРОК» в абсолютных величинах:**
      - Если рассматривать абстрактно любую сетку (будь то сетка тейк-профитов или сетка усреднения) в шкале абсолютных величин (`abs()`, модуль дистанции отклонения от точки входа), то вне зависимости от стороны (LONG или SHORT):
        - **ПОЛ (Floor, уровень исполнения, само действие / экзекьютор ордеров)** — **ВСЕГДА НИЖЕ** в абсолютной шкале:
          - *Для тейка:* пол = целевой процент профита (например, 2.0%).
          - *Для усреднения:* пол = глубина отката/уровня для выставления ордера (например, для лонга -8.0%, для шорта +8.0% -> по модулю `8.0%`).
        - **КУРОК (Activation, порог взведения пола)** — **ВСЕГДА ВЫШЕ** в абсолютной шкале:
          - *Для тейка:* курок взводится на более высокой прибыли (например, 3.5% > 2.0%).
          - *Для усреднения:* курок взводится при более глубокой просадке/импульсе (например, для лонга -10.5%, для шорта +10.5% -> по модулю `10.5% > 8.0%`).
      - **Механика отката:** Рынок импульсом преодолевает курок (взведение пола), а исполнение ордера экзекьютором (само действие) происходит **строго при откате цены назад к полу**.
      - **Полиморфизм крайнего уровня (`activation == floor`):**
        Для ВСЕХ стратегий системы, где используется трейлинг, на ПОСЛЕДНЕМ уровне курок выставляется строго вровень с полом (`activation == floor`). При достижении целевой отметки оба условия (`distance >= activation` и `distance <= floor`) выполняются одновременно: происходит мгновенное исполнение действия экзекьютором без ожидания отката.

  3. **Стартовый пул монет боевого бота (Инвариант ручного пула оператора):**

      - Ротация монет срабатывает строго и исключительно в момент автозакрытия позиций автоклозером в 100% кэш (`radar_rotation_on_close` под куполом `auto_closing.positive`).

  4. **Мульти-ротация обоймы монет (Top-N Rank & Swap) с 35% гистерезисом:**
      - И для воронки Самсонова (`samsonov_funnel`), и для Альфа-селектора (`alpha_coin_selector`) кандидаты и текущие монеты ранжируются по единой шкале скора.
      - Полноценная мульти-ротация: за один автоклоз может замениться от 0 до всех $N$ монет.
      - **Совпавшие монеты:** если монета из текущей обоймы входит в идеальный Top-N кандидатов, она безусловно сохраняется без лишних транзакций.
      - **Попарная замена несовпавших:** оставшиеся выбывающие монеты (от худшей к лучшей) попарно сравниваются с новыми претендентами из Top-N (от лучшего к худшему). Замена происходит **ТОЛЬКО** при отрыве по скору $\ge 35\%$:
        $$\frac{Score(C) - Score(W)}{\max(Score(W), 0.001)} \ge 35\%$$
      - Если отрыв кандидата $< 35\%$, старая монета сохраняется (защита гистерезисом от рыночного шума).
      - В полигоне (`cron3PapperUniverses`) режим `samsonov_funnel` жестко заблокирован во избежание взаимного дедлока (полигон сам поставляет данные для Радара); полигон использует исключительно `alpha_coin_selector`.   5. **Обязательный журнал ротаций (Боевой и Бумажный боты):**

### 7.8. Священный закон инициализации и дефолтов Старшего Тим Лида

1. **Прямой доступ к конфигурациям (Fail-Fast):**
   Все параметры конфигурации при инициализации читаются **СТРОГО напрямую через `cfg['key']`**, а **НЕ** через `cfg.get('key', default)`. При отсутствии ключа или ошибке в конфиге процесс обязан падать с немедленным `KeyError` на старте, а не маскировать проблему выдуманным дефолтом.
2. **Золотое правило дефолтов — `None` Type:**
   Если параметр действительно опционален, его дефолтным значением по умолчанию в сигнатурах функций и промежуточных вычислениях может быть **ТОЛЬКО `None`**.
3. **Абсолютное зло — `0` (ноль):**
   Числовой ноль запрещен в качестве слепого дефолта, так как он маскирует непроинициализированные переменные и является скрытой бомбой в торговых расчетах. Любое использование числового дефолта требует детального обоснования и согласования с Тим Лидом.
4. **Запрет скрытых подмен стратегий:**
   Запрещено неявно подставлять исторические или устаревшие стратегии (например, `u0`) при отсутствии явного указания.
