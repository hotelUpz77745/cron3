  2. **Универсальный архитектурный инвариант трейлинга: Геометрия «ПОЛ / КУРОК» в абсолютных величинах:**
      - Если рассматривать абстрактно любую сетку (будь то сетка тейк-профитов или сетка усреднения) в шкале абсолютных величин (`abs()`, модуль дистанции отклонения от точки входа), то вне зависимости от стороны (LONG или SHORT):
        - **ПОЛ (Floor, уровень исполнения, само действие / экзекьютор ордеров)** — **ВСЕГДА НИЖЕ** в абсолютной шкале:
          - *Для тейка:* пол = целевой процент профита (например, 2.0%).
          - *Для усреднения:* пол = глубина отката/уровня для выставления ордера (например, для лонга -8.0%, для шорта +8.0% -> по модулю `8.0%`).
        - **КУРОК (Activation, порог взведения пола)** — **ВСЕГДА ВЫШЕ** в абсолютной шкале:
          - *Для тейка:* курок взводится на более высокой прибыли (например, 3.5% > 2.0%).
          - *Для усреднения:* курок взводится при более глубокой просадке/импульсе (например, для лонга -10.5%, для шорта +10.5% -> по модулю `10.5% > 8.0%`).
      - **Механика отката:** Рынок импульсом преодолевает курок (взведение пола), а исполнение ордера экзекьютором (само действие) происходит **строго при откате цены назад к полу**.
      - **Полиморфизм крайнего уровня (`activation == floor`):**
        Для ВСЕХ стратегий системы, где используется трейлинг, на ПОСЛЕДНЕМ уровне курок выставляется строго вровень с полом (`activation == floor`). При достижении целевой отметки оба условия (`distance >= activation` и `distance <= floor`) выполняются одновременно: происходит мгновенное исполнение действия экзекьютором без ожидания отката.
